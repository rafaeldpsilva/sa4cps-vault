RQ1. How can intelligent buildings dynamically model and adapt to the user’s individual and group preferences using graph-based heterogeneous representations? 

RQ2. In what ways can LLMs and SLMs be employed, not only to infer user intent and contextual relevance, but also to interact with occupants through dialog for clarification, negotiation, and preference definition? 

RQ3. How can an agent identify a user's latent needs and autonomously discover, negotiate for, and deploy and use containerized services to address them? 

RQ4. What mechanisms are required to enable peer-to-peer sharing of resources, such as computational availability and sensor data, between the autonomous agents of different users while preserving privacy and individual control?

1. 🏡 Core Application Domain

- **Intelligent Buildings / Intelligent Facilities:** The target environment for the solution.
- **Adaptive Intelligent Communities:** The overarching framework name and focus on collective system behavior.
- **Human-Centric Adaptation:** Ensuring the system's response is tailored to human needs, which is the central motivation.
- **Real-Time Dynamics / Real-Time Interactions:** Requirement for the system's responsiveness to continuous changes in context and preference.

1. 🧠 User Modeling and AI
- **User Preference Modeling / Elicitation/ User Profiling:** The central problem of capturing and predicting human needs (RQ1, RQ2).
- **Context Awareness / Contextual Dynamics:** Recognizing the environmental and situational factors that influence preference (RQ1).
- **Graph Neural Networks (GNNs):** The specific machine learning technique used for preference modeling via **Heterogeneous Graphs** (RQ1).
- **Large Language Models (LLMs) / Small Language Models (SLMs):** Tools for natural interaction, intent inference, and dialogue (RQ2).
- **Latent Needs Discovery:** Inferring unstated or non-explicit user desires (RQ3).
- **Conflict Identification / Negotiation / Mediation:** Handling disagreements in multi-occupant scenarios (RQ2, Abstract).

3. ⚙️ System Architecture and Infrastructure

These keywords describe the structure and technical foundation of the system, addressing issues of scalability, reliability, and privacy.

- **Multi-Agent Architecture / Agentic Control:** The main paradigm for system control and decentralized decision-making (RQ0, RQ3).
- **Distributed Architecture / Decentralized Control:** The non-centralized nature of the system.
- **Digital Twin:** The simulated/virtual representation of the building environment (WP3).
- **Edge Computing / Edge Devices / Low Powered Devices:** The constraint on where processing must occur for latency and privacy benefits.
- **Microservice-Oriented Principles:** The design pattern for the scalable system architecture (WP2).

4. 🔗 Agent Functionality and Protocol

These keywords describe the specific behaviors and communication mechanisms of the autonomous agents.

- **Peer-to-Peer (P2P) Resource Sharing:** The mechanism for inter-agent data and computation exchange (RQ4).
- **Containerized Services / Dynamic Service Provisioning:** The agent's ability to discover and deploy new capabilities (RQ3).
- **Bounded Autonomy / Decision Logic:** The operational constraints and rules governing agent behavior (WP5).
- **Model Context Protocol (MCP):** The proposed schema for structuring context information for LLMs (WP1, T5.1).
- **Privacy-Preserving Architecture:** The requirement for handling sensitive data securely (RQ4, Objective 5).
