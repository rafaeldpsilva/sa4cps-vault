This thesis is expected to produce four original contributions.

**1. A Distributed Digital Twin Architecture for Edge-Based Intelligent Communities**

Defines the foundational infrastructure of the thesis: a container-orchestrated, edge-native architecture (the Caravels approach) in which each building is an autonomous node maintaining a live digital twin of its physical and digital resources, while cooperating as part of a community-level System of Systems. The purpose is to provide a modular, resource-efficient, and privacy-preserving substrate that runs on constrained edge hardware, keeps data and computation sovereignty at the building level, and lets the higher-level intelligence (preference modeling, agents, sharing) be deployed and coordinated across heterogeneous buildings.

**2. Context-Aware User Preference Elicitation using Heterogeneous Graph Neural Networks**

Addresses how the system learns and represents what users actually want. The purpose is to move beyond hand-built rules and static profiles to a heterogeneous graph representation of users, preferences, conditions, contexts, and values, over which graph neural networks learn context-dependent preferences and adapt to changing behavior. This gives the community a transparent, portable, and continuously-refined model of individual and multi-user preferences that services can query to personalize automation.

**3. Integrating LLMs with Model Context Protocol (MCP) for Grounded Agentic Control**

Connects natural-language intelligence to the system in a controlled way. The purpose is to use LLMs/SLMs as the reasoning and interaction layer, grounded through the Model Context Protocol so that models act on real, structured system context (twins, preferences, available services) rather than free-form generation. This enables natural-language preference elicitation, explanation, and agentic control while constraining the model to verified capabilities and data.

**4. Bounded Autonomy in Multi-Agent Systems: Conflict Resolution and Resource Sharing in Intelligent Communities**

Governs how autonomous agents cooperate without losing safety or sovereignty. The purpose is to define bounded-autonomy agents that resolve conflicting user preferences (multi-user cohabitation) and negotiate secure peer-to-peer sharing of data, services, and resources across buildings. This closes the loop from infrastructure to collective behavior, ensuring the community acts cooperatively and fairly while each building retains autonomy, privacy, and control over its own resources.
